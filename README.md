# Vesper EQ

Independent Windows x64 parametric equalizer with Vesper DSP integration.

Download the installer from [Releases](https://github.com/minseokk77/vesper-eq/releases/latest).
The installer includes the required APO DLL. The raw EXE alone is not a self-contained portable package.

With DSP running, EQ settings are sent to DSP; AutoEQ settings remain separate.

This repository distributes binaries and signed updater metadata. Application source is maintained separately.

[Website](https://vesper.minseok.online/eq)
